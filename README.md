# Credit Card Fraud Detection

A complete, modular Python project for detecting credit card fraud using machine learning, with best practices for imbalanced classification.

## Project Structure

```
credit_card_fraud_detection/
├── data/
│   └── creditcard.csv         # Place the dataset here
├── src/
│   ├── data_exploration.py
│   ├── preprocessing.py
│   ├── modeling.py
│   ├── evaluation.py
│   └── utils.py
├── main.py
├── requirements.txt
└── README.md
```

## Setup
1. Place `creditcard.csv` in the `data/` directory.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the project:
   ```bash
   python main.py
   ```

## Modules
- `data_exploration.py`: Data loading, exploration, visualization
- `preprocessing.py`: Data cleaning, scaling, balancing, splitting
- `modeling.py`: Model training and comparison
- `evaluation.py`: Metrics, plots, and insights
- `utils.py`: Helper functions
